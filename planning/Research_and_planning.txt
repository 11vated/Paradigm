Core Guarantee (repeated and hardened): same seed + same deterministic RNG + same engine = bit-identical output forever. This enables:

Verifiable provenance and lineage.
Breeding/mutation/evolution with genetic operators.
Cryptographic sovereignty (per-gene ownership, no mandatory blockchain).
Cross-domain composition via category theory functors.
Royalties, marketplaces, training canons, and user-owned AI ecosystems.

Key Abstractions:

UniversalSeed: JSON-serializable canonical structure ($gst, $domain, $hash, genes: {name: {type, value}}, $lineage, $sovereignty, etc.). Invariants enforced strictly (hash correctness, gene naming, determinism).
17/22-Type Gene System: Lattice/hierarchy (primitives → containers → spatial/temporal/symbolic/learned/meta). Each type defines its own mutate, crossover, distance, validate, and gradient ops. Runtime-derivable types with "law" verification.
Deterministic Developmental Engines: Staged pipelines (developmental biology analogy) per domain. 15+ built, 11+ planned.
GSPL: Domain-specific language for declaring/growing seeds, with lexer/parser/interpreter, type checker, bytecode, and @gpu annotations.
Evolution Stack: GA, MAP-Elites, CMA-ES, Novelty Search, AURORA, DQD, POET + refinement loops with Fisher Information Matrix.
Intelligence Layer: GSPL Agent (multi-stage, sub-agents, memory, tool-calling) for prompt → seed.
Sovereignty: ECDSA P-256 embedded signatures, per-gene provenance/licenses, WebAuthn/C2PA support.

Philosophy Alignment: Local-first, self-hosted, user ownership, modular, transparent, long-term maintainable. Strong anti-fragility via determinism.

Determinism Brittleness: Any overlooked non-deterministic path (e.g., in LLM sidecars, floating-point across arches, or dynamic imports) cascades. Browser/Node dep conflicts (fixed but symptomatic).
Complexity: 27 domains + 7 evo algos + functors + GSPL full stack = high cognitive load. Gene lattice derivation and law verification must be bulletproof or become tech debt.
Scalability Limits (Predicted):
Large populations/evolution: Compute (GPU strategy critical; sidecars help but orchestration needed).
Federated/P2P: Sync, conflict resolution, tombstoning.
Inverse pipeline + LLM grounding: Hallucination vs. determinism boundary.

Production Gaps: Full CI/CD maturity? Horizontal scaling tests? Observability depth (metrics/traces for grow/evolve)? Dependency risk audit (esp. LLM/inference). Mobile/offline story underdeveloped despite local-first ethos.
Security Surfaces: Per-gene permissions (authorization boundaries), signature nonces, .pseed import validation, agent tool calling sandboxing.
Maintainability: Many status/completion MD files suggest iterative/Agent-driven dev; needs consolidation for long-term.

Root Architectural Cause: Ambitious scope (full creative OS) vs. evolving implementation. Strong specs mitigate but code must perfectly mirror them.
